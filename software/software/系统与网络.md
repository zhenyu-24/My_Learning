## 7-Zip

**定位**：开源免费的压缩 / 解压工具，Windows 上事实标准。

**能干什么**

- 支持 7z、ZIP、TAR、GZ、XZ、BZIP2 等格式的**压缩和解压**
- RAR、ISO、CAB 等格式只支持**解压**（RAR 压缩算法有专利限制，7-Zip 不提供压缩）
- 右键菜单直接"提取到当前文件夹"，比资源管理器自带的好用
- 压缩率比 ZIP 高，7z 格式配合最大压缩适合长期归档

**下载**

- 官网：<https://www.7-zip.org/> → 选 `64-bit Windows x64` 的 `.exe` 或 `.msi`
- winget：`winget install --id 7zip.7zip -e`

> [!tip] 版本选择
> 现在基本都用 x64。只有 32 位老机器或需要给 ARM 设备装才考虑其他版本。官网首页会标注当前稳定版号。

## Neat Download Manager

**定位**：免费的多线程下载器，IDM 的轻量替代品。

**能干什么**

- 多线程分段下载，比浏览器单线程快，尤其在带宽充足但单连接被限速时
- 支持 HTTP / HTTPS / FTP，能抓取网页里的音视频资源
- 提供浏览器扩展，接管浏览器的下载请求
- 支持断点续传和下载队列

**下载**

- 官网：<https://www.neatdownloadmanager.com/> → Windows 版 `.exe` 或 macOS 版 `.dmg`
- 官网同时提供 Chrome / Firefox / Edge 扩展的安装入口

> [!warning] 它不是 BT 客户端
> NDM 只处理 HTTP(S)/FTP 直链，不支持磁力链接和种子。要下 BT 请用 qBittorrent 之类的工具。

## 图吧工具箱

**定位**：图拉丁吧出品的硬件检测工具合集，开源、免费、绿色（免安装）。

**能干什么**

- 一个入口集成 CPU-Z、GPU-Z、CrystalDiskInfo、AIDA64、Cinebench、FurMark 等大量硬件工具
- 装机验机时逐项检查：CPU 型号、内存颗粒、硬盘通电时间、显卡是否矿卡
- 压力测试和跑分，判断散热与稳定性
- 可在 WinPE 环境下运行，重装系统前先备份数据、检查硬件

**下载**

- 官网：<https://www.tbtool.cn/> → 下载最新版压缩包，解压即用

> [!warning] 只从官网下
> 这类工具合集在第三方站点被二次打包、捆绑广告的情况很常见。官网下载后建议核对文件哈希（官网会提供）。

## FlClash

**定位**：基于 ClashMeta 内核的开源多平台代理客户端。

**能干什么**

- 支持 Windows / macOS / Linux / Android，界面统一
- 订阅导入、规则分流、节点测速、流量统计
- 开源、无广告，不需要额外客户端授权

**下载**

- GitHub Releases：<https://github.com/chen08209/FlClash/releases>
- Windows 选 `-windows-amd64-setup.exe` 或免安装的 `.zip`；macOS 选 `.dmg`

> [!warning] 客户端不含节点
> 这类工具只是"壳"，需要你自己有可用的订阅或配置文件才能连通。请遵守所在地法律法规和网络使用规定。

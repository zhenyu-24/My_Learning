# 影音与录制

> [!info] 导航
> 返回 [[软件清单]]

## PotPlayer

**定位**：Windows 上本地视频播放器，轻量、解码全能。

**能干什么**

- 内置大量解码器，绝大多数格式直接播，不用另外装解码包
- 硬件解码支持好，4K / HDR 视频功耗低
- 支持倍速播放、逐帧、字幕加载（srt / ass）、音轨切换
- 可无级调节画面亮度、对比度、锐化，方便看暗场景
- 支持直播源和网络串流（m3u8 等）

**下载**

- 官网：<https://potplayer.tv/> → 选 `Download` 下的 64-bit 版本
- winget：`winget install --id Daum.PotPlayer -e`

> [!warning] 安装时注意捆绑
> 官方安装包在某些版本里会推荐附加组件。安装过程中留意勾选项，不需要的一律取消。

## OBS Studio

**定位**：开源免费的录屏与直播推流软件，行业标准。

**能干什么**

- 录屏：全屏、窗口、指定区域，可同时录摄像头和麦克风
- 直播：推流到 B 站、YouTube、Twitch 等任意 RTMP 平台
- 多场景切换、画中画、绿幕抠像
- 支持硬件编码（NVENC / QSV / AMF），录制时 CPU 占用低
- 插件生态丰富（虚拟摄像头、音频降噪等）

**下载**

- 官网：<https://obsproject.com/> → `Download` 自动识别你的系统
- winget：`winget install --id OBSProject.OBSStudio -e`

**上手三步**

1. `设置 → 输出` 选录像路径和编码器（有独显优先选硬件编码）
2. `来源` 里添加"显示器采集"或"窗口采集"
3. `设置 → 快捷键` 绑定开始/停止录制，然后点右下角"开始录制"

> [!tip] 录制卡顿先看编码器
> 用 CPU 软编码（x264）录 4K 很容易掉帧。换成 NVENC / QSV 后基本无感。

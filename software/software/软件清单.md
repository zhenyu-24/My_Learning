## 先用 winget 试

Windows 10/11 自带 `winget`，能装的就别手动下载安装包：

```powershell
winget install --id 7zip.7zip -e
winget install --id Obsidian.Obsidian -e
winget install --id OBSProject.OBSStudio -e
winget install --id CoreyButler.NVMforWindows -e
winget install --id Daum.PotPlayer -e
```

> [!tip] `-e` 是精确匹配
> 不加 `-e` 时 winget 会做模糊搜索，可能装错包。装之前可以 `winget search <关键字>` 先看一眼 ID。

## 安装包怎么选

| 后缀 | 含义 | 建议 |
| --- | --- | --- |
| `.exe` / `-setup.exe` | 安装程序 | 一般选这个，能自动关联文件类型 |
| `.msi` | Windows Installer 包 | 适合批量 / 静默部署 |
| `.zip` / `portable` | 免安装绿色版 | 放 U 盘、不想写注册表时用 |
| `.7z` | 需要先有 7-Zip 才能解 | 先装 7-Zip |

> [!warning] 认准下载入口
> GitHub 项目要在 **Releases** 页面下载，不要点首页的 "Code → Download ZIP"——那是源码，不是可执行程序。

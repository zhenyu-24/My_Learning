## Obsidian

**定位**：基于本地 Markdown 文件的笔记软件，数据完全归自己。

**能干什么**

- 笔记就是磁盘上的 `.md` 文件，随时能用别的编辑器打开，不怕厂商跑路
- 双向链接把笔记连成网络，配合关系图谱看知识结构
- 支持 Canvas 白板、表格、代码块、Mermaid 图表
- 插件生态庞大（日历、看板、Git 同步等），按需开启
- 多端同步可自选方案（Git、网盘、官方 Sync）

**下载**

- 官网：<https://obsidian.md/> → `Download` 选对应系统
- winget：`winget install --id Obsidian.Obsidian -e`

**几个实用习惯**

- 一个文件夹一个主题，根目录放一篇索引页做导航
- 用 frontmatter 打标签：`tags`、`created`
- 用 `> [!note]` / `> [!warning]` 这类 callout 做视觉分区
- 库目录纳入 Git 管理，但记得忽略 `.obsidian/workspace.json`（每台机器的窗口布局不同，提交会反复冲突）

> [!tip] 当前这个库
> 你现在看的笔记就在一个 Obsidian 库里，根目录是 `software/software`。

## Microsoft To Do

**定位**：微软的待办事项应用，轻量、跨平台、和 Outlook 打通。

**能干什么**

- 建立多个清单（工作 / 学习 / 购物），任务可设截止日期和提醒
- 支持子任务、附件、备注
- 「我的一天」每天挑几件今天必须做的事
- 与 Outlook 任务、Microsoft 365 同步
- Windows / macOS / iOS / Android / 网页全平台

**下载**

- 应用商店：<https://apps.microsoft.com/detail/9nblggh5r558>
- 手机端在各自应用商店搜 "Microsoft To Do"
- 网页版：<https://to-do.office.com>

> [!tip] 和 Obsidian 的分工
> 长期知识沉淀放 Obsidian，短周期的"今天要做什么"放 To Do。别把待办写进笔记里，容易变成永远不看的清单。
